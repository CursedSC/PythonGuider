Урок 3: Переменные и типы данных

≈ 20 минутНачальный
Цель урока: Понять, что такое переменные, как создавать их в Python, и познакомиться с основными типами данных: целые числа, дробные числа, строки и булевы значения.

Что такое переменная?

Представь, что у тебя есть коробка с наклейкой. На наклейке написано название, а внутри коробки лежит какой-то предмет. В программировании переменная — это такая «коробка» с именем, в которой можно хранить данные.

У каждой переменной есть:

  • Имя — по нему мы обращаемся к переменной (например, name, age, score).
  • Значение — то, что хранится в переменной (например, "Алихан", 17, 95.5).
  • Тип данных — определяет, какого рода информация хранится (число, текст и т.д.).

Создание переменных в Python

В Python переменная создаётся в тот момент, когда ты впервые присваиваешь ей значение. Для этого используется знак = (оператор присваивания).

Python
name = "Алихан"      # Переменная name хранит строку
age = 17             # Переменная age хранит целое число
height = 1.75        # Переменная height хранит дробное число
is_student = True    # Переменная is_student хранит логическое значение

print(name)
print(age)
print(height)
print(is_student)

Результат:

Результат
Алихан
17
1.75
True

Обрати внимание: Python сам определяет тип переменной по тому, какое значение мы в неё положили. Это называется динамическая типизация.

Основные типы данных в Python

1. Целые числа (int)

Целые числа — положительные, отрицательные и ноль без дробной части.

Python
students = 25
temperature = -5
zero = 0
big_number = 1_000_000  # Подчёркивания для удобства чтения

print(type(students))   #

2. Дробные числа (float)

Числа с плавающей точкой — числа с дробной частью.

Python
price = 199.99
pi = 3.14159
negative_float = -0.5

print(type(pi))  #

3. Строки (str)

Строка — это последовательность символов (текст). В Python строки заключаются в кавычки: одинарные ('...') или двойные ("...").

Python
city = "Нальчик"
language = 'Python'
empty = ""  # Пустая строка

print(type(city))  #

4. Булевы значения (bool)

Логический тип данных, который может принимать только два значения: True (истина) или False (ложь).

Python
is_python_easy = True
is_raining = False

print(type(is_python_easy))  #
Важно: True и False пишутся с большой буквы! true или TRUE — неправильно, Python выдаст ошибку.

Правила именования переменных

В Python есть несколько правил для имён переменных:

  • Имя может содержать буквы (латиницу), цифры и знак подчёркивания _.
  • Имя не может начинаться с цифры.
  • Нельзя использовать зарезервированные слова Python (if, for, while, class и др.).
  • Python чувствителен к регистру: name и Name — это разные переменные.
Python
# Правильные имена
user_name = "Алихан"
age2 = 17
_salary = 50000

# Неправильные имена (раскомментируй — будет ошибка)
# 2name = "Ошибка"     # Нельзя начинать с цифры
# if = 10              # Нельзя использовать ключевые слова
# my-name = "Ошибка"   # Дефис не разрешён (используй _)

Изменение значений переменных

Значение переменной можно изменить в любой момент. Новая «коробка» заменит старую.

Python
x = 10
print(x)  # 10

x = 25
print(x)  # 25

x = "Теперь тут строка"
print(x)  # Теперь тут строка

Python позволяет даже изменить тип данных, хранящихся в переменной (хотя на практике лучше так не делать без необходимости).

Задание для самопроверки

Создай переменные для хранения следующей информации о себе:

  1. Имя (строка)
  2. Фамилия (строка)
  3. Возраст (целое число)
  4. Рост в метрах (дробное число)
  5. Любишь ли ты программировать (булево значение)

Выведи тип каждой переменной с помощью функции type().

Python
first_name = "Алихан"
last_name = "Гергоков"
age = 17
height = 1.78
loves_programming = True

print(type(first_name))       # 
print(type(last_name))        # 
print(type(age))              # 
print(type(height))           # 
print(type(loves_programming))#
