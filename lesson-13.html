Модули math и random

Знакомимся со стандартной библиотекой Python: модули math для математики и random для случайных чисел.

Цель урока: научиться подключать модули с помощью import и использовать функции из стандартной библиотеки для математических вычислений и генерации случайных чисел.

Что такое модуль и как его подключить?

Модуль — это файл с Python-кодом, который можно подключить к своей программе. Python поставляется с огромной стандартной библиотекой готовых модулей.

Python — способы импорта
import math          # Весь модуль
import random        # Весь модуль

from math import pi  # Только константу pi
from math import sqrt, ceil  # Несколько имён

import math as m     # С псевдонимом

Модуль math

Содержит математические функции и константы.

Функция / константаОписаниеПример
math.piЧисло π ≈ 3.14159math.pi → 3.141592...
math.eЧисло e ≈ 2.71828math.e → 2.71828...
math.sqrt(x)Квадратный кореньmath.sqrt(16) → 4.0
math.pow(x, y)x в степени ymath.pow(2, 10) → 1024.0
math.floor(x)Округление внизmath.floor(3.7) → 3
math.ceil(x)Округление вверхmath.ceil(3.1) → 4
math.abs(x)Модуль числа (используйте abs())abs(-5) → 5
math.log(x)Натуральный логарифмmath.log(math.e) → 1.0
Python — math на практике
import math

# Длина окружности
r = 5
perimeter = 2 * math.pi * r
print(f"Длина окружности: {perimeter:.2f}")  # 31.42

# Гипотенуза прямоугольного треугольника
a, b = 3, 4
c = math.sqrt(a**2 + b**2)
print(f"Гипотенуза: {c}")  # 5.0

# Можно через math.hypot
print(math.hypot(3, 4))  # 5.0

Модуль random

Генерирует случайные числа — незаменим для игр, тестовых данных, симуляций.

ФункцияОписаниеПример
random.random()Случайный float от 0.0 до 1.00.734...
random.randint(a, b)Случайный int от a до b включительноrandom.randint(1, 6)
random.choice(seq)Случайный элемент из последовательностиrandom.choice([1,2,3])
random.shuffle(lst)Перемешать список (in-place)random.shuffle(cards)
random.sample(seq, k)k случайных уникальных элементовrandom.sample(range(100), 5)
random.uniform(a, b)Случайный float от a до brandom.uniform(1.0, 5.0)
Python — random на практике
import random

# Бросок кубика
dice = random.randint(1, 6)
print(f"Кубик выпал: {dice}")

# Случайный выбор
fruits = ["яблоко", "банан", "вишня", "манго"]
chosen = random.choice(fruits)
print(f"Сегодня ешь: {chosen}")

# Перемешать колоду карт
deck = list(range(1, 53))
random.shuffle(deck)
print(f"Первые 5 карт: {deck[:5]}")

# Лотерея: 6 чисел из 1-49
lottery = random.sample(range(1, 50), 6)
lottery.sort()
print(f"Лотерея: {lottery}")

Мини-игра: «Угадай число»

Python
import random

secret = random.randint(1, 100)
attempts = 0

print("Я загадал число от 1 до 100. Угадай!")

while True:
    try:
        guess = int(input("Твоя попытка: "))
    except ValueError:
        print("Введи целое число!")
        continue

    attempts += 1

    if guess < secret:
        print("Слишком мало!")
    elif guess > secret:
        print("Слишком много!")
    else:
        print(f"Угадал! Понадобилось {attempts} попыток."
        break

Задание для самопроверки

Используя модули math и random, напишите программу:

  1. Генерирует 5 случайных чисел от 1 до 100
