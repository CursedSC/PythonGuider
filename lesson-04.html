Урок 4: Ввод и вывод данных

≈ 15 минутНачальный
Цель урока: Научиться выводить данные на экран с помощью print() и запрашивать информацию у пользователя через input().

Вывод данных: функция print()

Функция print() — основное средство вывода информации в Python. Она выводит переданные ей аргументы в консоль (на экран).

Python
# Вывод одной строки
print("Привет!")

# Вывод нескольких аргументов (через запятую)
name = "Алихан"
age = 17
print("Имя:", name, "Возраст:", age)

# Вывод чисел и результатов вычислений
print(2 + 2)
print(10 * 5)
Результат
Привет!
Имя: Алихан Возраст: 17
4
50

Параметры print():

  • sep — разделитель между аргументами (по умолчанию пробел).
  • end — что выводить в конце (по умолчанию перевод строки \n).
Python
# Меняем разделитель
print("яблоко", "груша", "слива", sep=", ")

# Меняем конец строки
print("Первая строка", end=" → ")
print("Вторая строка")

f-строки (форматированные строки)

f-строки — удобный способ вставлять значения переменных прямо в текст. Достаточно поставить букву f перед кавычками, а переменные заключить в фигурные скобки {}.

Python
name = "Алихан"
age = 17
city = "Нальчик"

print(f"Меня зовут {name}, мне {age} лет, я из города {city}.")
print(f"Через 5 лет мне будет {age + 5} лет.")
Результат
Меня зовут Алихан, мне 17 лет, я из города Нальчик.
Через 5 лет мне будет 22 лет.

Ввод данных: функция input()

Функция input() позволяет запросить данные у пользователя. Программа останавливается и ждёт, пока пользователь введёт текст и нажмёт Enter. Результат всегда возвращается как строка.

Python
name = input("Введите ваше имя: ")
print(f"Привет, {name}!")
Важно: input() всегда возвращает строку (str)! Если нужно число, преобразуй результат с помощью int() или float().

Преобразование типов при вводе

Python
# Ввод числа
age_str = input("Сколько тебе лет? ")  # age_str — строка
age = int(age_str)                      # age — целое число
print(f"Через год тебе будет {age + 1} лет.")

# Можно короче — преобразовать сразу
height = float(input("Введи свой рост (в метрах): "))
print(f"Твой рост: {height} м")

Простейшая программа-диалог

Python
print("— Привет! Давай познакомимся.")
name = input("— Как тебя зовут? ")
age = int(input(f"— {name}, сколько тебе лет? "))
city = input("— Из какого ты города? ")

print(f"\nОтлично, {name}! Тебе {age} лет, ты из города {city}.")
print("Добро пожаловать в мир Python!")

Задание для самопроверки

Напиши программу-калькулятор, которая:

  1. Запрашивает у пользователя два числа.
  2. Выводит их сумму, разность, произведение и частное.
Python
print("=== Калькулятор ===")
a = float(input("Введи первое число: "))
b = float(input("Введи второе число: "))

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} * {b} = {a * b}")
if b != 0:
    print(f"{a} / {b} = {a / b}")
else:
    print("На ноль делить нельзя!")
