Функции в Python

def и return

Функция — это именованный блок кода, который можно вызывать многократно. Функции помогают избежать дублирования кода и делают программу более структурированной.

Синтаксис

Синтаксис
def имя_функции(параметры):
    """Документация (описание функции)"""
    # тело функции
    return результат  # необязательно

Примеры

Python — функция без return
def greet(name):
    print(f"Привет, {name}!")

greet("Алихан")  # Привет, Алихан!
Python — функция с return 
def add(a, b):
    result = a + b
    return result

summa = add(5, 3)
print(summa)  # 8

Возвращаемое значение: return завершает выполнение функции и возвращает указанное значение. Если return отсутствует, функция возвращает None.

Аргументы функций

Позиционные аргументы

Передаются в том же порядке, в котором указаны в определении функции.

Python
def describe_person(name, age, city):
    print(f"{name}, {age} лет, город {city}")

describe_person("Алихан", 17, "Нальчик")

Именованные аргументы

Передаются с указанием имени параметра — порядок не важен.

Python
describe_person(age=17, city="Нальчик", name="Алихан")

Значения по умолчанию

Параметрам можно задать значение по умолчанию — тогда при вызове их можно не указывать.

Python
def greet(name, greeting="Привет"):
    print(f"{greeting}, {name}!")

greet("Алихан")             # Привет, Алихан!
greet("Алихан", "Здравствуй")  # Здравствуй, Алихан!
