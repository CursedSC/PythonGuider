Словари и множества в Python

Словарь (dict)

Словарь — коллекция пар «ключ: значение». Ключи уникальны. Создаётся с помощью фигурных скобок {} или функции dict().

Python
student = {
    "name": "Алихан",
    "age": 17,
    "grade": "10А"
}

# Доступ по ключу
print(student["name"])         # Алихан
print(student.get("phone"))    # None (не вызывает ошибку)

# Добавление / изменение
student["city"] = "Нальчик"
student["age"] = 18

# Удаление
del student["grade"]
print(student)

Методы словарей

МетодОписание
.keys()Возвращает все ключи
.values()Возвращает все значения
.items()Возвращает пары (ключ, значение)
.get(key, default)Значение по ключу (или default, если нет)
.pop(key)Удалить ключ и вернуть его значение
.update(d2)Обновить словарь данными из d2
.clear()Очистить словарь
Python — Перебор словаря
person = {"name": "Алихан", "age": 17, "city": "Нальчик"}

# Перебор пар ключ-значение
for key, value in person.items():
    print(f"{key}: {value}")

# Проверка наличия ключа
if "name" in person:
    print("Имя есть!")

Множество (set)

Множество — неупорядоченная коллекция уникальных элементов. Используется для удаления дубликатов и проверки вхождения.

Python
nums = {1, 2, 3, 2, 1, 4}
print(nums)     # {1, 2, 3, 4} — дубликаты удалены

# Удаление дубликатов из списка
lst = [1, 2, 2, 3, 3, 3, 4]
unique = list(set(lst))
print(unique)   # [1, 2, 3, 4]

# Операции над множествами
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(a | b)    # {1, 2, 3, 4, 5, 6} — объединение
print(a & b)    # {3, 4}             — пересечение
print(a - b)    # {1, 2}             — разность
Проверка x in set работает намного быстрее, чем x in list, особенно на больших данных — это одно из главных применений множества.
