Урок 5: Условный оператор if-else

≈ 20 минутБазовый
Цель урока: Научиться использовать условный оператор if-elif-else для создания разветвляющихся алгоритмов и освоить операции сравнения.

Операции сравнения

Прежде чем изучать условный оператор, нужно познакомиться с операциями сравнения. Они сравнивают два значения и возвращают True или False.

ОператорЗначениеПример
==Равно5 == 5 → True
!=Не равно5 != 3 → True
>Больше10 > 5 → True
<Меньше3 < 8 → True
>=Больше или равно5 >= 5 → True
<=Меньше или равно4 <= 5 → True

Конструкция if

if (если) — базовая конструкция для проверки условия. Если условие истинно (True), выполняется блок кода внутри if.

Python
age = 18

if age >= 18:
    print("Ты совершеннолетний!")
    print("Можешь получить водительские права.")

print("Эта строка выполнится в любом случае")
Важно: В Python отступы обязательны! Они показывают, какие строки относятся к блоку if. Обычно используется 4 пробела на один отступ. Следи, чтобы все строки в блоке имели одинаковый отступ.

Конструкция if-else

else (иначе) позволяет указать, что делать, если условие ложно.

Python
temperature = 15

if temperature > 20:
    print("На улице тепло, можно идти в футболке.")
else:
    print("На улице прохладно, лучше надеть куртку.")

Конструкция if-elif-else

elif (сокращение от else if) — позволяет проверить несколько условий подряд.

Python
score = 85

if score >= 90:
    grade = "Отлично (5)"
elif score >= 75:
    grade = "Хорошо (4)"
elif score >= 60:
    grade = "Удовлетворительно (3)"
else:
    grade = "Нужно подучить (2)"

print(f"Твой балл: {score}. Оценка: {grade}")

Проверка идёт сверху вниз. Как только находится первое истинное условие — выполняется соответствующий блок, а остальные проверки пропускаются.

Логические операторы

Для объединения нескольких условий используются логические операторы:

  • and — оба условия должны быть истинны.
  • or — хотя бы одно условие истинно.
  • not — отрицание условия.
Python
age = 16
has_parent_permission = True

if age >= 18 or has_parent_permission:
    print("Можно зарегистрироваться на сайте.")

is_weekend = True
is_sunny = False
if is_weekend and not is_sunny:
    print("Выходной, но пасмурно — пойду программировать!")

Задание для самопроверки

Напиши программу, которая запрашивает у пользователя три числа и определяет, какое из них самое большое.

Python
a = float(input("Введи первое число: "))
b = float(input("Введи второе число: "))
c = float(input("Введи третье число: "))

if a >= b and a >= c:
    largest = a
elif b >= a and b >= c:
    largest = b
else:
    largest = c

print(f"Самое большое число: {largest}")
