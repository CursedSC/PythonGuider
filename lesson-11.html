Работа с файлами

Учимся читать и записывать данные в текстовые файлы — основа любого приложения, которому нужно сохранять информацию.

Цель урока: научиться открывать файлы, читать их содержимое и записывать данные с помощью функции open() и оператора with.

Зачем нужны файлы?

До сих пор все данные в наших программах хранились только в памяти — после завершения программы они исчезали. Файлы позволяют сохранять данные на диск, чтобы они оставались после перезапуска.

Файлы используются повсюду: конфигурации программ, базы данных, логи, экспорт результатов. Умение работать с файлами — обязательный навык программиста.

Функция open() и режимы

Для работы с файлом используется функция open(имя_файла, режим). Режим определяет, что мы хотим делать с файлом.

РежимОписание
'r'Чтение (по умолчанию). Файл должен существовать
'w'Запись. Создаёт файл, или перезаписывает существующий
'a'Дозапись в конец файла (append)
'x'Создание нового файла. Ошибка, если файл уже есть
'r+'Чтение и запись одновременно
Python
# Открытие файла для чтения
f = open("notes.txt", "r", encoding="utf-8")
content = f.read()
f.close()  # Важно: всегда закрывать файл!

# Открытие файла для записи
f = open("notes.txt", "w", encoding="utf-8")
f.write("Привет, файл!")
f.close()
Всегда указывайте encoding="utf-8" при работе с текстовыми файлами, содержащими кириллицу — иначе Python может неправильно прочитать текст.

Оператор with (контекстный менеджер)

Вместо того чтобы вручную вызывать f.close(), используйте with — он автоматически закроет файл в конце блока, даже если произошла ошибка.

Python — with (рекомендуемый способ)
# Запись в файл
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Первая строка\n")
    f.write("Вторая строка\n")
# Файл закрыт автоматически

# Чтение всего файла
with open("notes.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
Оператор with — стандарт в Python. Используйте его всегда при работе с файлами.

Методы чтения

У файлового объекта есть несколько методов чтения:

Python
with open("notes.txt", "r", encoding="utf-8") as f:
    # read() — весь текст одной строкой
    text = f.read()

with open("notes.txt", "r", encoding="utf-8") as f:
    # readline() — одна строка (включая \n)
    line = f.readline()
    print(repr(line))  # 'Первая строка\n'

with open("notes.txt", "r", encoding="utf-8") as f:
    # readlines() — список всех строк
    lines = f.readlines()
    print(lines)  # ['Первая строка\n', 'Вторая строка\n']

# Перебор строк напрямую (экономит память)
with open("notes.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

Запись и дозапись

Python
# writelines() — записать список строк
tasks = ["Сделать домашнее задание\n", "Учить Python\n", "Погулять\n"]
with open("tasks.txt", "w", encoding="utf-8") as f:
    f.writelines(tasks)

# Режим 'a' — дозаписать в конец, не удаляя существующее
with open("tasks.txt", "a", encoding="utf-8") as f:
    f.write("Ещё одна задача\n")

# Проверяем результат
with open("tasks.txt", "r", encoding="utf-8") as f:
    for i, line in enumerate(f, start=1):
        print(f"{i}: {line.strip()}")

Практика: дневник

Напишем простой дневник, который добавляет записи в файл и умеет их показывать.

Python — дневник
FILENAME = "diary.txt"

def add_entry(text):
    with open(FILENAME, "a", encoding="utf-8") as f:
        f.write(text + "\n")
    print("Запись добавлена!")

def show_all():
    try:
        with open(FILENAME, "r", encoding="utf-8") as f:
            lines = f.readlines()
        if not lines:
            print("Дневник пуст.")
        else:
            print(f"Всего записей: {len(lines)}")
            for i, line in enumerate(lines, 1):
                print(f"{i}. {line.strip()}")
    except FileNotFoundError:
        print("Файл не найден — дневник ещё пустой.")

# Главное меню
while True:
    print("\n1. Добавить запись  2. Показать всё  0. Выход")
    choice = input("Выбор: ").strip()
    if choice == "1":
        text = input("Запись: ")
        add_entry(text)
    elif choice == "2":
        show_all()
    elif choice == "0":
        break
