Урок 6: Цикл while

≈ 20 минут Начальный
Цель урока: Понять, что такое цикл и зачем он нужен. Научиться использовать цикл while для повторения действий, управлять циклом с помощью break и continue.

Что такое цикл и зачем он нужен?

Представь, что тебе нужно вывести на экран числа от 1 до 100. Писать сто команд print() — не лучшая идея. Для таких задач в программировании существуют циклы — конструкции, позволяющие выполнять одни и те же действия многократно.

В Python есть два основных цикла: while и for. В этом уроке разберём цикл while.

Аналогия: Цикл — это как будильник, который звонит каждый день до тех пор, пока ты не нажмёшь кнопку «Выключить». Условие остановки определяешь ты сам.

Синтаксис цикла while

Цикл while выполняет блок кода до тех пор, пока условие истинно (True). Как только условие становится ложным (False), цикл останавливается.

Синтаксис 
while условие:
    # тело цикла (выполняется, пока условие True)
    действие

Посмотрим на простой пример — считаем от 1 до 5:

Python 
count = 1          # Счётчик — начинаем с 1

while count <= 5:  # Пока счётчик не превысил 5
    print(count)   # Выводим текущее значение
    count += 1     # Увеличиваем счётчик на 1

print("Готово!")
Результат
1
2
3
4
5
Готово!
Важно: Обязательно изменяй счётчик или условие внутри цикла! Если условие никогда не станет ложным, программа зависнет в бесконечном цикле.

Бесконечный цикл и оператор break

Иногда заранее неизвестно, сколько раз нужно выполнить цикл. Например, программа должна принимать ввод от пользователя, пока тот не введёт «стоп». В таком случае используют бесконечный цикл с условием True и ключевое слово break для выхода.

Python 
print("Введи числа. Напиши 'стоп' для завершения.")

total = 0

while True:                        # Бесконечный цикл
    user_input = input("Число: ")

    if user_input == "стоп":       # Условие выхода
        break                      # Прерываем цикл

    number = int(user_input)
    total += number
    print(f"Текущая сумма: {total}")

print(f"Итоговая сумма: {total}")

break — это «аварийный выход» из цикла. Как только Python встречает break, он немедленно прекращает выполнение цикла и переходит к коду после него.

Оператор continue — пропуск итерации

Ключевое слово continue позволяет пропустить текущую итерацию и перейти к следующей проверке условия. Это полезно, когда нужно пропустить определённые значения.

Выведем только чётные числа от 1 до 10:

Python 
num = 1

while num <= 10:
    if num % 2 != 0:  # Если число нечётное
        num += 1
        continue      # Пропускаем print и переходим к следующей итерации

    print(num)        # Эта строка выполняется только для чётных чисел
    num += 1
Результат
2
4
6
8
10
Разница между break и continue:
— break — полностью выходит из цикла.
— continue — пропускает остаток текущей итерации и переходит к следующей.

Практический пример: игра «Угадай число»

Объединим всё, что узнали, в небольшой игре:

Python 
secret = 42       # Загаданное число
attempts = 0      # Счётчик попыток

print("Я загадал число от 1 до 100. Угадай!")

while True:
    guess = int(input("Твой вариант: "))
    attempts += 1

    if guess < secret:
        print("Загаданное число больше!")
    elif guess > secret:
        print("Загаданное число меньше!")
    else:
        print(f"Правильно! Ты угадал за {attempts} попытки.")
        break   # Число угадано — выходим из цикла

Задание для самопроверки

Вопрос: Что выведет следующий код?

Python
i = 0
while i < 5:
    i += 1
    if i == 3:
        continue
    print(i)

Вывод: 1, 2, 4, 5 (каждое число на отдельной строке).

Пояснение: Когда i становится равным 3, срабатывает continue — вывод числа 3 пропускается, и цикл переходит к следующей итерации (i=4). Числа 1, 2, 4, 5 выводятся нормально.
