Урок 9: Функции

≈ 25 минут Средний
Цель урока: Научиться создавать собственные функции с помощью def, передавать параметры, возвращать значения с помощью return и понять область видимости переменных.

Зачем нужны функции?

Представь, что в программе одно и то же действие выполняется в разных местах — например, расчёт скидки на товар. Копировать одинаковый код несколько раз неудобно: если нужно что-то изменить, придётся исправлять везде. Функция позволяет дать имя блоку кода и вызывать его в любом месте программы.

Функции — это один из главных инструментов программиста. Они помогают:

  • Избежать повторения кода (принцип DRY — Don't Repeat Yourself).
  • Разбить большую программу на логические части.
  • Сделать код понятным и лёгким для изменения.

Создание и вызов функции

Функция определяется с помощью ключевого слова def, за которым следуют имя функции и круглые скобки.

Синтаксис
def имя_функции():
    # тело функции

имя_функции()  # вызов функции
Python 
def greet():
    print("Привет!")
    print("Добро пожаловать на сайт.")

greet()   # Вызов — выполняет тело функции
greet()   # Можно вызвать сколько угодно раз
Результат
Привет!
Добро пожаловать на сайт.
Привет!
Добро пожаловать на сайт.

Параметры и аргументы

Параметры — это переменные, которые функция принимает на вход (объявляются в скобках при определении функции). Аргументы — это конкретные значения, передаваемые при вызове.

Python 
def greet(name):          # name — параметр
    print(f"Привет, {name}!")

greet("Алихан")           # "Алихан" — аргумент
greet("Марина")           # другой аргумент

# Функция с двумя параметрами
def introduce(name, age):
    print(f"Меня зовут {name}, мне {age} лет.")

introduce("Алихан", 17)
Результат
Привет, Алихан!
Привет, Марина!
Меня зовут Алихан, мне 17 лет.
Параметры по умолчанию: можно задать значение, которое используется, если аргумент не передан: def greet(name="друг"):. Тогда greet() выведет «Привет, друг!».

Возврат значения — return

Функция может не только выводить что-то на экран, но и возвращать результат с помощью return. Это значение можно сохранить в переменную и использовать дальше.

Python 
def square(number):
    return number * number   # Возвращаем результат

result = square(5)           # Сохраняем в переменную
print(result)                # 25

# Можно использовать сразу в выражении
print(square(3) + square(4))  # 9 + 16 = 25


def average(numbers):
    """Вычисляет среднее значение списка."""
    return sum(numbers) / len(numbers)

marks = [4, 5, 3, 5, 4]
print(f"Средний балл: {average(marks):.1f}")
return завершает функцию. Код после return не выполняется. Функция без return автоматически возвращает None.

Область видимости переменных

Переменные, созданные внутри функции, доступны только внутри неё — это локальные переменные. Переменные вне функции называются глобальными.

Python 
message = "Я глобальная переменная"

def show():
    local_var = "Я локальная"  # Видна только внутри show()
    print(message)             # Глобальная видна внутри функции
    print(local_var)

show()
print(message)
# print(local_var)  # Ошибка! local_var не существует вне функции

Задание для самопроверки

Задача: Напиши функцию is_even(n), которая возвращает True, если число чётное, и False, если нечётное. Проверь её на числах 4 и 7.

Python
def is_even(n):
    return n % 2 == 0  # True если остаток от деления на 2 равен нулю

print(is_even(4))  # True
print(is_even(7))  # False
