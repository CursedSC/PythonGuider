Строки в Python

Создание строк

Строка (str) — это последовательность символов. Строки можно создавать с помощью одинарных, двойных или тройных кавычек.

Python
s1 = 'Одинарные кавычки'
s2 = "Двойные кавычки"
s3 = """Многострочная
строка"""
s4 = f"f-строка: {2 + 2}"  # Результат: "f-строка: 4"

print(len(s1))  # 17 — длина строки

Основные методы строк

МетодОписаниеПример
.upper()Все символы в верхний регистр"python".upper() → "PYTHON"
.lower()Все символы в нижний регистр"PYTHON".lower() → "python"
.strip()Убрать пробелы по краям" hi ".strip() → "hi"
.replace(a, b)Заменить все вхождения a на b"aabb".replace("a","x") → "xxbb"
.split(sep)Разбить строку по разделителю в список"a,b,c".split(",") → ["a","b","c"]
.join(list)Соединить список в строку",".join(["a","b"]) → "a,b"
.find(sub)Найти позицию подстроки (−1 если нет)"Python".find("th") → 2
.startswith(s)Начинается ли строка с s?"Hello".startswith("He") → True
.endswith(s)Заканчивается ли строка на s?"test.py".endswith(".py") → True
.count(sub)Количество вхождений подстроки"banana".count("a") → 3
Python — Примеры методов
name = "  Алихан  "
print(name.strip())          # "Алихан"
print(name.strip().upper())  # "АЛИХАН"

sentence = "python это круто"
words = sentence.split()     # ['python', 'это', 'круто']
print(" | ".join(words))     # "python | это | круто"

Индексация и срезы

Строки, как и списки, поддерживают индексацию (с нуля) и срезы.

Python
s = "Python"
print(s[0])     # P
print(s[-1])    # n
print(s[1:4])   # yth
print(s[::-1])  # nohtyP  (перевернуть строку)
Строки в Python неизменяемы — нельзя поменять символ по индексу. Нужно создать новую строку: s = s[:2] + "X" + s[3:].

f-строки (форматирование)

f-строки (f-strings) — самый удобный способ вставить значение переменной в строку. Символ f ставится перед кавычкой, выражения заключаются в {}.

Python
name = "Алихан"
age = 17
pi = 3.14159

print(f"Привет, {name}! Тебе {age} лет.")
print(f"Пи ≈ {pi:.2f}")       # Два знака после запятой
print(f"2^10 = {2 ** 10}")    # Выражение прямо внутри {}
