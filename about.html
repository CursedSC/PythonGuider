О проекте

«Python: первые программы» — бесплатный образовательный ресурс для школьников, которые хотят научиться программировать с нуля на русском языке.

Цель проекта

Дать школьникам 7–11 классов простой, понятный и бесплатный старт в программировании на Python — без лишней теории, сразу к практике.

Для кого создан

Для школьников, учителей информатики и всех, кто хочет начать программировать с нуля. Никакого предварительного опыта не требуется.

Почему Python?

Python — самый популярный язык для обучения в мире. Простой синтаксис, огромное сообщество, разрешён на ЕГЭ по информатике. Идеальный первый язык.

Чем полезен

Полностью на русском языке. Бесплатный доступ ко всем 18 урокам, справочнику, примерам кода и встроенному редактору.

Темы, которые изучаются

Курс построен по принципу «от простого к сложному» — каждый урок опирается на предыдущий.

Блок Темы Уроки
Основы Что такое Python, установка, первая программа, переменные и типы данных, ввод и вывод 1–3

Структуры Списки, кортежи, словари, множества, функции 8–9

Продвинутый Основы ООП (классы, объекты), рекурсия 16–17
