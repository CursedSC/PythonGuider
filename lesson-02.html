Урок 2: Установка Python и первый запуск

≈ 15 минут Начальный
Цель урока: Установить Python на свой компьютер, познакомиться с IDLE (встроенной средой разработки) и запустить свою первую программу.

Как установить Python

Python можно установить на Windows, macOS или Linux. Процесс установки очень простой и займёт всего несколько минут.

Установка на Windows

  1. Перейди на официальный сайт: python.org/downloads
  2. Нажми на большую жёлтую кнопку «Download Python 3.x.x» (где x.x — последняя версия).
  3. Дождись загрузки установочного файла и запусти его.
  4. Важно! На первом экране установки обязательно поставь галочку «Add Python to PATH» (Добавить Python в PATH).
  5. Нажми «Install Now» и дождись окончания установки.
Важно: Галочка «Add Python to PATH» обязательна! Если её не поставить, Python не будет работать из командной строки, и придётся переустанавливать.

Проверка установки

После установки открой командную строку (Win+R → введи cmd → Enter) и введи команду:

Командная строка
python --version

Если ты увидишь что-то вроде Python 3.12.0 — установка прошла успешно!

Знакомство с IDLE

Вместе с Python устанавливается IDLE (Integrated Development and Learning Environment) — простая, но удобная среда для написания и запуска кода. IDLE отлично подходит для начинающих.

Чтобы открыть IDLE: нажми «Пуск» → введи «IDLE» → выбери «IDLE (Python 3.x)».

После запуска ты увидишь окно с текстом — это интерактивная оболочка (Shell). В ней можно вводить команды Python и сразу видеть результат.

Твоя первая программа!

Давай напишем и запустим самую первую программу. В окне IDLE введи следующую строку и нажми Enter:

Python
print("Привет, мир!")

Ты должен увидеть:

Результат
Привет, мир!

Поздравляю! Ты только что написал и запустил свою первую программу на Python. Функция print() выводит текст на экран — подробнее о ней мы поговорим в уроке 4.

Совет: Попробуй изменить текст в кавычках на что-то своё и снова нажми Enter. Экспериментируй — это лучший способ учиться!

Создание и запуск файла .py

Вводить команды по одной в Shell удобно для экспериментов, но настоящие программы хранятся в файлах с расширением .py. Давай создадим такой файл.

  1. В меню IDLE выбери File → New File (или нажми Ctrl+N).
  2. Откроется новое окно редактора. Напиши в нём несколько строк кода.
  3. Сохрани файл: File → Save (Ctrl+S), назови его, например, my_first_program.py.
  4. Запусти программу: Run → Run Module (F5).

Результат выполнения появится в окне Shell. Теперь ты умеешь создавать и запускать Python-программы из файлов!

Задание для самопроверки

Выполни следующие действия:

  1. Открой IDLE и создай новый файл.
  2. Напиши в нём программу, которая выводит три строки: твоё имя, твой возраст и твой любимый школьный предмет.
  3. Сохрани файл и запусти его.
Python
print("Меня зовут Алихан")
print("Мне 17 лет")
print("Мой любимый предмет — информатика")
