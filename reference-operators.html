Операторы в Python

Арифметические операторы

Используются для математических вычислений над числами.

ОператорНазваниеПримерРезультат
+Сложение5 + 38
-Вычитание10 - 46
*Умножение3 * 412
/Деление (вещественное)7 / 23.5
//Целочисленное деление7 // 23
%Остаток от деления7 % 21
**Возведение в степень2 ** 8256
Python
print(17 // 5)   # 3  — целая часть от деления
print(17 % 5)    # 2  — остаток
print(2 ** 10)   # 1024
Оператор % (модуль) очень полезен для проверки чётности: n % 2 == 0 — число чётное.

Операторы сравнения

Сравнивают два значения и возвращают булевый результат: True или False.

ОператорЗначениеПримерРезультат
==Равно5 == 5True
!=Не равно5 != 3True
>Больше7 > 4True
<Меньше3 < 2False
>=Больше или равно5 >= 5True
<=Меньше или равно4 <= 3False
Внимание: == (сравнение) и = (присвоение) — это разные операторы! if x = 5 — синтаксическая ошибка.

Логические операторы

Комбинируют несколько условий в одно.

ОператорОписаниеПримерРезультат
andИстинно, если оба условия истинныTrue and FalseFalse
orИстинно, если хотя бы одно условие истинноTrue or FalseTrue
notИнвертирует условиеnot TrueFalse
Python
age = 17
has_permit = False

# and — нужно, чтобы оба условия были True
if age >= 18 and has_permit:
    print("Можно водить")
else:
    print("Нельзя водить")

# or — достаточно одного True
if age >= 16 or has_permit:
    print("Можно ехать как пассажир")
