Генераторы списков и словарей

List comprehension — синтаксис

Генератор списка создаёт новый список из существующей последовательности в одну строку.

ФормаСинтаксис
Простой[expr for x in iterable]
С фильтром[expr for x in iterable if condition]
С if-else[a if cond else b for x in iterable]
Вложенный[expr for x in iter1 for y in iter2]
Python
# Квадраты чисел
[x**2 for x in range(1, 6)]          # [1, 4, 9, 16, 25]

# Только чётные квадраты
[x**2 for x in range(1, 11) if x % 2 == 0]  # [4, 16, 36, 64, 100]

# Метка чётности
["чётное" if x % 2 == 0 else "нечётное" for x in range(5)]

# Таблица умножения 3×3
[(i, j, i*j) for i in range(1, 4) for j in range(1, 4)]

Dict comprehension

Python
# Квадраты чисел в словаре
{x: x**2 for x in range(1, 6)}
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Фильтрация словаря — оставить только положительные
d = {"a": 3, "b": -1, "c": 5, "d": -2}
positives = {k: v for k, v in d.items() if v > 0}
# {'a': 3, 'c': 5}

# Инверсия словаря
original = {"один": 1, "два": 2, "три": 3}
inverted = {v: k for k, v in original.items()}
# {1: 'один', 2: 'два', 3: 'три'}

Set comprehension и generator expression

Python
# Set comprehension — фигурные скобки без двоеточия
{x % 3 for x in range(10)}  # {0, 1, 2} — уникальные остатки

# Generator expression — круглые скобки, не создаёт список
# (экономит память для больших данных)
total = sum(x**2 for x in range(1000))  # считает без создания списка
print(total)  # 332833500
Генераторные выражения (x for x in ...) ленивые — вычисляют элементы по одному, не загружая всё в память. Используйте их в sum(), any(), all() для экономии памяти.
