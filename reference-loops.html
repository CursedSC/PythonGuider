Циклы в Python

Цикл while

Цикл while выполняет блок кода до тех пор, пока условие остаётся истинным. Используется, когда заранее неизвестно, сколько раз нужно повторить действие.

Синтаксис

Синтаксис
while условие:
    # тело цикла (выполняется, пока условие True)

Пример

Python
count = 1
while count <= 5:
    print(f"Итерация номер {count}")
    count += 1
# Вывод: Итерация номер 1, 2, 3, 4, 5
Осторожно — бесконечный цикл! Если условие никогда не станет ложным, программа зависнет. Например: while True: print("Бесконечность..."). Для выхода используй break.

Цикл for

Цикл for используется для перебора элементов последовательности (строки, списка, результата range()). В отличие от while, количество итераций обычно известно заранее.

Синтаксис

Синтаксис
for переменная in последовательность:
    # тело цикла

Примеры

Python — перебор строки
for letter in "Python":
    print(letter)
# P, y, t, h, o, n — каждая буква на новой строке
Python — перебор списка
fruits = ["яблоко", "груша", "слива"]
for fruit in fruits:
    print(f"Я люблю {fruit}")

Функция range()

range() генерирует последовательность чисел и чаще всего используется вместе с циклом for.

Синтаксис

Синтаксис
range(stop)              # от 0 до stop-1
range(start, stop)        # от start до stop-1
range(start, stop, step)  # с шагом step
ПараметрТипОбязательныйОписание
startintНетНачальное значение (по умолчанию 0)
stopintДаКонечное значение (не включается в последовательность)
stepintНетШаг (по умолчанию 1, может быть отрицательным)

Примеры

Python
# От 0 до 4
for i in range(5):
    print(i)  # 0 1 2 3 4

# От 3 до 7
for i in range(3, 8):
    print(i)  # 3 4 5 6 7

# От 10 до 1 с шагом -2
for i in range(10, 0, -2):
    print(i)  # 10 8 6 4 2

Операторы break и continue

break — немедленно прерывает выполнение цикла. continue — пропускает оставшуюся часть текущей итерации и переходит к следующей.

Python — break
for i in range(10):
    if i == 5:
        break
    print(i)  # 0 1 2 3 4
Python — continue
for i in range(5):
    if i == 2:
        continue
    print(i)  # 0 1 3 4
