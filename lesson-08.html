Урок 8: Списки

≈ 25 минут Начальный
Цель урока: Научиться создавать списки, обращаться к элементам по индексу, изменять списки и использовать основные методы: append(), remove(), sort(), len().

Что такое список?

До сих пор мы хранили одно значение в одной переменной: name = "Алихан". Но что если нужно хранить несколько значений сразу — например, список оценок или имена учеников? Для этого в Python есть список (list).

Список — это упорядоченная коллекция элементов, заключённых в квадратные скобки [] и разделённых запятыми. Элементы могут быть любого типа: числа, строки, и даже другие списки.

Python 
grades = [5, 4, 5, 3, 4]          # Список чисел
names = ["Алихан", "Марина", "Саша"]  # Список строк
empty = []                          # Пустой список

print(grades)   # [5, 4, 5, 3, 4]
print(names)    # ['Алихан', 'Марина', 'Саша']
print(len(grades))  # 5 — количество элементов

Индексация — доступ к элементам

Каждый элемент списка имеет свой индекс — порядковый номер, начинающийся с нуля. Чтобы получить элемент, нужно указать его индекс в квадратных скобках.

Python 
fruits = ["яблоко", "банан", "вишня", "груша"]
#          индекс:    0        1         2       3

print(fruits[0])   # яблоко
print(fruits[1])   # банан
print(fruits[-1])  # груша  (последний элемент)
print(fruits[-2])  # вишня  (предпоследний)

# Изменение элемента
fruits[1] = "апельсин"
print(fruits)  # ['яблоко', 'апельсин', 'вишня', 'груша']
Нумерация с нуля! Первый элемент имеет индекс 0, второй — 1 и так далее. Отрицательные индексы считают с конца: -1 — последний, -2 — предпоследний.

Срезы — часть списка

Срез (slice) позволяет получить подсписок — несколько элементов подряд. Синтаксис: список[начало:конец] (конец не включается).

Python 
numbers = [10, 20, 30, 40, 50, 60]

print(numbers[1:4])   # [20, 30, 40]  — индексы 1, 2, 3
print(numbers[:3])    # [10, 20, 30]  — от начала до индекса 2
print(numbers[3:])    # [40, 50, 60]  — от индекса 3 до конца
print(numbers[:])     # [10, 20, 30, 40, 50, 60] — весь список (копия)

Основные методы списков

Список — это объект с набором встроенных методов для изменения и анализа данных.

Python 
cities = ["Нальчик", "Москва", "Казань"]

# append() — добавить элемент в конец
cities.append("Сочи")
print(cities)  # ['Нальчик', 'Москва', 'Казань', 'Сочи']

# insert() — вставить на определённую позицию
cities.insert(1, "Владикавказ")
print(cities)  # ['Нальчик', 'Владикавказ', 'Москва', 'Казань', 'Сочи']

# remove() — удалить по значению
cities.remove("Казань")
print(cities)  # ['Нальчик', 'Владикавказ', 'Москва', 'Сочи']

# pop() — удалить по индексу (по умолчанию последний)
removed = cities.pop()
print(removed)  # Сочи
print(cities)   # ['Нальчик', 'Владикавказ', 'Москва']

# sort() — сортировка по возрастанию
cities.sort()
print(cities)  # ['Владикавказ', 'Москва', 'Нальчик']

# reverse() — перевернуть список
cities.reverse()
print(cities)  # ['Нальчик', 'Москва', 'Владикавказ']

# count() — подсчёт вхождений
nums = [1, 2, 3, 2, 2, 4]
print(nums.count(2))  # 3
Встроенные функции для списков: len(список) — длина, min(список) — минимум, max(список) — максимум, sum(список) — сумма числовых элементов.

Перебор списка с помощью for

Цикл for, изученный в прошлом уроке, отлично работает со списками:

Python 
grades = [5, 4, 3, 5, 4, 5, 3]

total = 0
for grade in grades:
    total += grade

average = total / len(grades)
print(f"Средний балл: {average:.1f}")  # :.1f — один знак после запятой
Результат
Средний балл: 4.1

Задание для самопроверки

Задача: Дан список nums = [3, 1, 4, 1, 5, 9, 2, 6]. Как получить только первые три элемента? Как добавить число 7 в конец? Как узнать максимальный элемент?

Python
nums = [3, 1, 4, 1, 5, 9, 2, 6]

print(nums[:3])        # [3, 1, 4] — срез первых трёх
nums.append(7)         # Добавляем 7 в конец
print(nums)            # [3, 1, 4, 1, 5, 9, 2, 6, 7]
print(max(nums))       # 9 — максимальный элемент
