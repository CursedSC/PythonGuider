Урок 1: Что такое Python и как он работает

≈ 10 минут Начальный
Цель урока: Познакомиться с языком Python, узнать его историю, основные области применения и понять, почему Python — отличный выбор для первого языка программирования.

Что такое Python?

Python — это высокоуровневый язык программирования общего назначения. Его создал голландский программист Гвидо ван Россум в 1991 году. Название языка произошло не от змеи, а от популярного британского комедийного шоу «Летающий цирк Монти Пайтона» (Monty Python's Flying Circus).

Python был задуман как язык с простым и понятным синтаксисом, который легко читается и пишется. Его философия изложена в документе «Дзен Python» (The Zen of Python), который включает принципы вроде «Простое лучше сложного» и «Читаемость имеет значение».

Совет: Чтобы увидеть «Дзен Python», достаточно ввести команду import this в интерпретаторе Python. Попробуй после установки!

Почему Python так популярен?

По данным рейтингов TIOBE и PYPL, Python стабильно занимает первое место среди самых популярных языков программирования в мире. Этому есть несколько причин:

  • Простой синтаксис. Код на Python похож на псевдокод — его легко читать даже человеку без технического образования.
  • Универсальность. Python применяется в веб-разработке, анализе данных, машинном обучении, автоматизации, создании игр и многом другом.
  • Огромное сообщество. Миллионы разработчиков по всему миру создают библиотеки, пишут руководства и отвечают на вопросы новичков.
  • Бесплатность. Python — свободное программное обеспечение с открытым исходным кодом.

Где используют Python?

Python применяется в самых разных сферах. Вот лишь несколько примеров:

  • Веб-разработка: Instagram, YouTube, Pinterest частично написаны на Python (с использованием фреймворков Django и Flask).
  • Наука и анализ данных: NASA, CERN и тысячи учёных используют Python для обработки экспериментов и моделирования.
  • Искусственный интеллект: TensorFlow, PyTorch — ведущие библиотеки машинного обучения — написаны для Python.
  • Автоматизация: Python позволяет писать скрипты для автоматической обработки файлов, отправки писем, сбора данных с сайтов.
  • Образование: Python — официальный язык на олимпиадах по программированию и разрешён к использованию на ОГЭ и ЕГЭ по информатике.

Твоя первая программа на Python (мысленно)

Пока мы ещё не установили Python, давай просто посмотрим, как выглядит простейшая программа. Не волнуйся, если что-то непонятно — всему научимся постепенно!

Python 
# Это комментарий — он не выполняется, а служит пояснением
print("Привет, мир!")  # Выводим надпись на экран

name = "Алихан"         # Создаём переменную и сохраняем в ней имя
age = 17                # Создаём переменную и сохраняем возраст

print("Меня зовут", name)       # Выводим имя
print("Мне", age, "лет")       # Выводим возраст
print("Я учусь программировать на Python!")

Если запустить этот код, на экране появится:

Результат
Привет, мир!
Меня зовут Алихан
Мне 17 лет
Я учусь программировать на Python!

Обрати внимание: команды выполняются последовательно, сверху вниз. Сначала выводится «Привет, мир!», потом имя, потом возраст, потом мотивационная фраза. Это главный принцип работы любой программы!

Как устроен Python изнутри (кратко)

Когда ты пишешь код на Python, происходит следующее:

  1. Интерпретатор Python читает твой код строка за строкой.
  2. Каждая строка переводится в специальный байт-код — промежуточное представление, понятное виртуальной машине Python.
  3. Виртуальная машина Python (PVM) выполняет этот байт-код.
  4. Результат выводится на экран.

В отличие от некоторых других языков (например, C++ или Java), Python не требует отдельного этапа компиляции перед запуском. Это делает процесс разработки очень быстрым: написал код — сразу запустил — увидел результат.

Важно запомнить: Python — интерпретируемый язык. Тебе не нужно компилировать программу перед запуском — достаточно просто запустить файл с кодом, и интерпретатор выполнит его.

Задание для самопроверки

Вопрос: Какие из перечисленных утверждений о Python верны?

  1. Python — компилируемый язык, требующий сборки перед запуском.
  2. Python назван в честь комедийного шоу.
  3. Python используют только для веб-разработки.
  4. Python разрешён к использованию на ЕГЭ по информатике.
  5. Код на Python выполняется последовательно, сверху вниз.

Верные утверждения: 2, 4, 5.

Пояснение: Python — интерпретируемый язык (1 неверно). Python назван в честь шоу «Монти Пайтон» (2 верно). Python используют в самых разных сферах (3 неверно). Python действительно разрешён на ЕГЭ (4 верно). Код выполняется построчно сверху вниз (5 верно).
