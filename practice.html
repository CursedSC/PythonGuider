Практические задания

Закрепи знания на практике! Реши задачи самостоятельно, а затем сравни своё решение с примером.

Простые задачи

Подходят для начинающих — достаточно знать первые 3–4 урока.

01

Приветствие по имени

Начальный

Задача: Напиши программу, которая спрашивает имя пользователя и выводит персональное приветствие.

Пример вывода
Как тебя зовут? Алихан
Привет, Алихан! Добро пожаловать в мир Python!
Python
name = input("Как тебя зовут? ")
print(f"Привет, {name}! Добро пожаловать в мир Python!")
02

Положительное или отрицательное

Начальный

Задача: Спроси у пользователя число и определи: оно положительное, отрицательное или равно нулю.

Пример вывода
Введи число: -7
Число -7 — отрицательное.
Python
n = int(input("Введи число: "))

if n > 0:
    print(f"Число {n} — положительное.")
elif n < 0:
    print(f"Число {n} — отрицательное.")
else:
    print("Число равно нулю.")

Список любимых предметов

Начальный

Задача: Создай список своих любимых школьных предметов и выведи их пронумерованно.

Пример вывода
Мои любимые предметы:
1. Информатика
2. Математика

Python
subjects = ["Информатика", "Математика", "Физика"]

Мини-проекты

Небольшие программы с реальной логикой — для тех, кто прошёл уроки 5–9.

П1

Простой калькулятор

Мини-проект

Задача: Создай консольный калькулятор, который выполняет 4 действия. Пользователь вводит два числа и выбирает операцию из меню.

Требования:

  • Меню с выбором операции (+, -, *, /)
  • Проверка деления на ноль
  • Повторять цикл до выбора «Выйти»
Пример работы
Калькулятор
1 — Сложение
2 — Вычитание
3 — Умножение
4 — Деление
0 — Выйти

Выбор: 1
Первое число: 15
Второе число: 7
15 + 7 = 22
Python
def calculate(a, b, op):
    if op == "1":
        return f"{a} + {b} = {a + b}"
    elif op == "2":
        return f"{a} - {b} = {a - b}"
    elif op == "3":
        return f"{a} * {b} = {a * b}"
    elif op == "4":
        if b == 0:
            return "Ошибка: деление на ноль!"
        return f"{a} / {b} = {a / b}"

while True:
    print("\nКалькулятор")
    print("1 — Сложение\n2 — Вычитание\n3 — Умножение\n4 — Деление\n0 — Выйти")
    choice = input("\nВыбор: ").strip()

    if choice == "0":
        print("До свидания!")
        break
    if choice not in ("1", "2", "3", "4"):
        print("Неверный выбор")
        continue

    a = float(input("Первое число: "))
    b = float(input("Второе число: "))
    print(calculate(a, b, choice))
П2

Список дел

Мини-проект

Задача: Программа «Список дел» — можно добавлять, просматривать и удалять задачи.

Требования:

  • Добавить задачу (пользователь вводит текст)
  • Показать все задачи с номерами
  • Удалить задачу по номеру
  • Выход из программы
Python
tasks = []

while True:
    print("\n=== Список дел ===")
    print("1 — Добавить задачу")
    print("2 — Показать все")
    print("3 — Удалить задачу")
    print("0 — Выйти")

    choice = input("Выбор: ").strip()

    if choice == "1":
        task = input("Новая задача: ").strip()
        if task:
            tasks.append(task)
            print(f"Добавлено: «{task}»")
        else:
            print("Задача не может быть пустой.")

    elif choice == "2":
        if not tasks:
            print("Список пуст.")
        else:
            for i, t in enumerate(tasks, 1):
                print(f"  {i}. {t}")

    elif choice == "3":
        if not tasks:
            print("Нечего удалять.")
        else:
            for i, t in enumerate(tasks, 1):
                print(f"  {i}. {t}")
            try:
                n = int(input("Номер для удаления: "))
                removed = tasks.pop(n - 1)
                print(f"Удалено: «{removed}»")
            except (ValueError, IndexError):
                print("Неверный номер.")

    elif choice == "0":
        print("До свидания!")
        break
П3

Угадай число (упрощённый)

Мини-проект

Задача: Компьютер загадывает случайное число от 1 до 50. Игрок угадывает с подсказками «больше» / «меньше». Ограничение: не более 7 попыток.

Python
import random

secret = random.randint(1, 50)
max_attempts = 7
attempts = 0

print("Я загадал число от 1 до 50. У тебя 7 попыток!")

while attempts < max_attempts:
    attempts += 1
    remaining = max_attempts - attempts + 1

    try:
        guess = int(input(f"Попытка {attempts}/{max_attempts}: "))
    except ValueError:
        print("Введи целое число!")
        attempts -= 1
        continue

    if guess == secret:
        print(f"Правильно! Ты угадал за {attempts} попыток.")
        break
    elif guess < secret:
        print(f"Моё число больше. Осталось попыток: {remaining - 1}")
    else:
        print(f"Моё число меньше. Осталось попыток: {remaining - 1}")
else:
    print(f"Попытки кончились! Загаданное число: {secret}")

Анализ оценок

Продвинутый

Задача: Программа принимает список оценок студентов, вычисляет среднее, находит максимальную и минимальную оценку, выводит количество отличников (оценка ≥ 4.5).

Python
grades = [4.8, 3.2, 5.0, 4.5, 2.9, 4.0, 4.9, 3.7, 5.0, 4.2]

avg = sum(grades) / len(grades)
max_grade = max(grades)
min_grade = min(grades)
excellent = sum(1 for g in grades if g >= 4.5)

print(f"Всего оценок: {len(grades)}")
print(f"Средняя оценка: {avg:.2f}")
print(f"Максимальная: {max_grade}")
print(f"Минимальная: {min_grade}")
print(f"Отличников (≥4.5): {excellent}")
И2

Счётчик слов

Продвинутый

Задача: Программа получает текст и подсчитывает, сколько раз встречается каждое слово. Результат сортируется по убыванию частоты.

Python
text = input("Введи текст: ").lower()
words = text.split()

counts = {}
for word in words:
    word = word.strip(".,!?;:")
    counts[word] = counts.get(word, 0) + 1

sorted_words = sorted(counts.items(), key=lambda x: x[1], reverse=True)

print("\nЧастота слов:")
for word, count in sorted_words:
    print(f"  {word}: {count}")

Простые числа (решето Эратосфена)

Продвинутый

Задача: Выведи все простые числа до N, используя алгоритм «Решето Эратосфена». N вводит пользователь.

Python
n = int(input("Найти простые числа до: "))

sieve = [True] * (n + 1)
sieve[0] = sieve[1] = False

for i in range(2, int(n**0.5) + 1):
    if sieve[i]:
        for j in range(i*i, n + 1, i):
            sieve[j] = False

primes = [i for i, is_prime in enumerate(sieve) if is_prime]
print(f"Простые числа до {n}: {primes}")

Шифр Цезаря

Продвинутый

Задача: Реализуй шифрование и расшифровку методом «Шифр Цезаря». Пользователь вводит текст, сдвиг и режим (зашифровать/расшифровать).

Python
def caesar(text, shift, mode="encrypt"):
    if mode == "decrypt":
        shift = -shift
    result = []
    for ch in text:
        if ch.isalpha():
            base = ord('А') if ch.upper() >= 'А' else ord('a')
            if ch.upper() >= 'А':
                base = ord('А')
                shifted = (ord(ch.upper()) - ord('А') + shift) % 32
                new_ch = chr(ord('А') + shifted)
                result.append(new_ch.lower() if ch.islower() else new_ch)
            else:
                shifted = (ord(ch.lower()) - ord('a') + shift) % 26
                new_ch = chr(ord('a') + shifted)
                result.append(new_ch.upper() if ch.isupper() else new_ch)
        else:
            result.append(ch)
    return "".join(result)

text = input("Текст: ")
shift = int(input("Сдвиг: "))
mode = input("Режим (encrypt/decrypt): ").strip()
print("Результат:", caesar(text, shift, mode))
И5

Класс «Банковский счёт»

Продвинутый

Задача: Создай класс BankAccount с методами пополнения, снятия и просмотра баланса. Предусмотри защиту от отрицательного баланса.

Python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            print("Сумма должна быть положительной.")
            return
        self.balance += amount
        print(f"Пополнено на {amount} руб. Баланс: {self.balance} руб.")

    def withdraw(self, amount):
        if amount <= 0:
            print("Сумма должна быть положительной.")
        elif amount > self.balance:
            print("Недостаточно средств.")
        else:
            self.balance -= amount
            print(f"Снято {amount} руб. Баланс: {self.balance} руб.")

    def show(self):
        print(f"Счёт: {self.owner}, баланс: {self.balance} руб.")

acc = BankAccount("Алихан", 1000)
acc.show()
acc.deposit(500)
acc.withdraw(200)
acc.withdraw(2000)
acc.show()
