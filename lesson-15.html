Словари: углублённо

Вложенные словари, сортировка, подсчёт частот и другие продвинутые техники работы с dict.

Цель урока: освоить вложенные словари, сортировку по значениям и подсчёт частот — паттерны, которые используются в реальных задачах.

Вложенные словари

Значениями словаря могут быть другие словари — это позволяет хранить структурированные данные.

Python
students = {
    "Алихан": {"age": 17, "grade": "А", "scores": [85, 92, 78]},
    "Асель":  {"age": 16, "grade": "Б", "scores": [90, 88, 95]},
    "Тимур":  {"age": 17, "grade": "А", "scores": [72, 68, 80]},
}

# Доступ к вложенным данным
print(students["Алихан"]["grade"])        # А
print(students["Асель"]["scores"][0])     # 90

# Добавить нового студента
students["Диана"] = {"age": 16, "grade": "В", "scores": [88, 90, 91]}

# Перебор
for name, info in students.items():
    avg = sum(info["scores"]) / len(info["scores"])
    print(f"{name}: среднее = {avg:.1f}")

Сортировка словаря

Словарь нельзя сортировать напрямую, но можно получить отсортированные пары:

Python
scores = {"Алихан": 85, "Асель": 92, "Тимур": 68, "Диана": 90}

# Сортировка по значениям (по убыванию)
sorted_by_score = sorted(scores.items(), key=lambda x: x[1], reverse=True)
for name, score in sorted_by_score:
    print(f"{name}: {score}")
# Асель: 92
# Диана: 90
# Алихан: 85
# Тимур: 68

# Найти максимальное значение
best = max(scores, key=scores.get)
print(f"Лучший результат: {best} ({scores[best]})")

Подсчёт частот

Один из самых распространённых паттернов — подсчитать, сколько раз встречается каждый элемент:

Python
text = "banana"
freq = {}
for char in text:
    freq[char] = freq.get(char, 0) + 1
print(freq)  # {'b': 1, 'a': 3, 'n': 2}

# Метод get с дефолтом — идиоматично!
# freq.get(char, 0) возвращает 0, если ключа нет

# Найти самый частый символ
most_common = max(freq, key=freq.get)
print(f"Самый частый: '{most_common}' ({freq[most_common]} раз)")
# Самый частый: 'a' (3 раз)
В стандартной библиотеке есть collections.Counter, который делает то же самое автоматически: from collections import Counter; Counter("banana").

Группировка данных

Python — группировка по признаку
students = [
    ("Алихан", "10А"), ("Асель", "10Б"),
    ("Тимур", "10А"), ("Диана", "10Б"), ("Руслан", "10А")
]

# Сгруппировать по классу
by_class = {}
for name, cls in students:
    if cls not in by_class:
        by_class[cls] = []
    by_class[cls].append(name)

for cls, names in sorted(by_class.items()):
    print(f"{cls}: {', '.join(names)}")
# 10А: Алихан, Тимур, Руслан
# 10Б: Асель, Диана
