Урок 10: Итоговый проект — Записная книжка

≈ 30 минут Средний
Цель урока: Применить все изученные темы — переменные, ввод-вывод, условия, циклы, списки и функции — в одном полноценном проекте: консольной записной книжке.

Что мы будем создавать?

Мы напишем программу-записную книжку, которая умеет:

  • Добавлять записи (имя + номер телефона).
  • Выводить список всех записей.
  • Искать запись по имени.
  • Удалять запись по имени.
  • Выходить из программы.

Это консольная программа — она работает в терминале, без графического интерфейса. Именно с таких программ начинается путь любого программиста!

Совет: Перед написанием кода всегда полезно сделать план — что программа должна уметь делать и как это реализовать. Такой подход называется алгоритмическим мышлением.

Шаг 1: Структура данных

Для хранения контактов будем использовать список словарей (каждый словарь — один контакт с полями name и phone). Но чтобы не усложнять, упростим: будем хранить контакты как список строк в формате «Имя: Номер».

Начнём с простого варианта — хранение в двух параллельных списках:

Python 
names = []   # Список имён
phones = []  # Список телефонов (индексы совпадают с names)

Шаг 2: Функции для каждого действия

Разобьём логику на отдельные функции — по одной на каждое действие пользователя:

Python 
def add_contact(names, phones):
    """Добавить новый контакт."""
    name = input("Имя: ").strip()
    phone = input("Телефон: ").strip()
    names.append(name)
    phones.append(phone)
    print(f"Контакт '{name}' добавлен.")


def show_all(names, phones):
    """Показать все контакты."""
    if not names:
        print("Книжка пуста.")
        return
    print("\n=== Все контакты ===")
    for i, (name, phone) in enumerate(zip(names, phones), start=1):
        print(f"{i}. {name}: {phone}")
    print()


def search_contact(names, phones):
    """Найти контакт по имени."""
    query = input("Введи имя для поиска: ").strip().lower()
    found = False
    for i, name in enumerate(names):
        if query in name.lower():
            print(f"Найден: {name} — {phones[i]}")
            found = True
    if not found:
        print("Контакт не найден.")


def delete_contact(names, phones):
    """Удалить контакт по имени."""
    query = input("Введи имя для удаления: ").strip()
    if query in names:
        index = names.index(query)
        names.pop(index)
        phones.pop(index)
        print(f"Контакт '{query}' удалён.")
    else:
        print("Контакт не найден.")

Шаг 3: Главный цикл программы

Теперь соединим все функции в главном цикле, который показывает меню и обрабатывает выбор пользователя:

Python 
def main():
    names = []
    phones = []

    print("=== Записная книжка ===")

    while True:
        print("\nМеню:")
        print("1 — Добавить контакт")
        print("2 — Показать все")
        print("3 — Найти контакт")
        print("4 — Удалить контакт")
        print("0 — Выйти")

        choice = input("\nВаш выбор: ").strip()

        if choice == "1":
            add_contact(names, phones)
        elif choice == "2":
            show_all(names, phones)
        elif choice == "3":
            search_contact(names, phones)
        elif choice == "4":
            delete_contact(names, phones)
        elif choice == "0":
            print("До свидания!")
            break
        else:
            print("Неверный ввод. Выбери цифру от 0 до 4.")

# Запуск программы
main()

Что использовали в проекте?

Оглянись назад — в этом коротком проекте задействованы почти все темы курса:

  • Переменные — names, phones, choice
  • Ввод/вывод — input(), print()
  • Условия — if-elif-else для обработки меню
  • Цикл while — главный цикл программы
  • Цикл for — перебор контактов в show_all() и search_contact()
  • Списки — хранение имён и телефонов
  • Функции — разделение логики на add_contact, show_all и т.д.
