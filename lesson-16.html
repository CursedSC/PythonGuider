Основы объектно-ориентированного программирования

Знакомимся с классами и объектами — мощным способом организации кода в Python.

Цель урока: понять концепцию классов и объектов, научиться создавать классы с атрибутами и методами, использовать __init__ и self.

Что такое ООП?

Объектно-ориентированное программирование (ООП) — способ организации кода, при котором данные и функции объединяются в объекты. Объект создаётся по шаблону — классу.

Аналогия: класс — это чертёж дома, объект — конкретный дом, построенный по этому чертежу. Один чертёж — много домов.

Создание класса

Python — первый класс
class Student:
    # __init__ вызывается при создании объекта
    def __init__(self, name, age):
        self.name = name  # атрибут объекта
        self.age = age

    def greet(self):
        print(f"Привет! Я {self.name}, мне {self.age} лет.")

    def is_adult(self):
        return self.age >= 18

# Создание объектов
s1 = Student("Алихан", 17)
s2 = Student("Асель", 18)

s1.greet()        # Привет! Я Алихан, мне 17 лет.
print(s1.name)    # Алихан
print(s2.is_adult())  # True

Методы и атрибуты

self — это ссылка на сам объект. Каждый метод класса получает его первым аргументом.

Python — класс с методами
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount
        print(f"Пополнено на {amount}. Баланс: {self.balance}")

    def withdraw(self, amount):
        if amount > self.balance:
            print("Недостаточно средств!")
        else:
            self.balance -= amount
            print(f"Снято {amount}. Баланс: {self.balance}")

    def __str__(self):  # Для print(объект)
        return f"Счёт {self.owner}: {self.balance} руб."

acc = BankAccount("Алихан", 1000)
acc.deposit(500)    # Пополнено на 500. Баланс: 1500
acc.withdraw(200)   # Снято 200. Баланс: 1300
print(acc)          # Счёт Алихан: 1300 руб.
