Условные конструкции в Python

if-elif-else

Условный оператор позволяет выполнять разные блоки кода в зависимости от выполнения заданного условия. Это основа для создания разветвляющихся алгоритмов.

Синтаксис

Синтаксис
if условие1:
    # блок кода, если условие1 истинно
elif условие2:
    # блок кода, если условие2 истинно
else:
    # блок кода, если ни одно условие не истинно
ЧастьОбязательностьОписание
ifОбязательноНачало условной конструкции. Проверяет первое условие.
elifНеобязательноМожет быть несколько. Проверяет дополнительное условие, если предыдущие были ложны.
elseНеобязательноВыполняется, если все условия оказались ложными.

Как работает

Условия проверяются сверху вниз. Как только находится первое истинное условие — выполняется соответствующий блок кода, а все остальные блоки пропускаются. Если ни одно условие не истинно — выполняется блок else (если он есть).

Частая ошибка: После условия обязательно ставится двоеточие :. Забытое двоеточие — одна из самых частых ошибок у начинающих.

Примеры

Python — Простое условие
age = 16
if age >= 18:
    print("Можно голосовать")
else:
    print("Голосовать пока нельзя")
Python — Множественные условия
score = 82
if score >= 90:
    grade = "Отлично"
elif score >= 75:
    grade = "Хорошо"
elif score >= 60:
    grade = "Удовлетворительно"
else:
    grade = "Нужно подучить"
print(f"Оценка: {grade}")  # Оценка: Хорошо

match-case (Python 3.10+)

Конструкция match-case (структурное сопоставление с образцом) появилась в Python 3.10. Это аналог оператора switch из других языков, но с более широкими возможностями.

Синтаксис

Синтаксис
match значение:
    case образец1:
        # действие 1
    case образец2:
        # действие 2
    case _:
        # действие по умолчанию (wildcard)

Пример

Python
day = "суббота"
match day:
    case "понедельник" | "вторник" | "среда" | "четверг" | "пятница":
        print("Будний день — идём в школу")
    case "суббота" | "воскресенье":
        print("Выходной — программируем!")
    case _:
        print("Такого дня недели не существует")
Совет: Если твоя версия Python ниже 3.10, используй конструкцию if-elif-else — она работает во всех версиях.
